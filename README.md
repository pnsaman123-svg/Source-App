# SOURCE Smart Energy Mobile App

High-fidelity React Native (Expo) mobile application designed for smart home energy telemetry, net metering, solar production, battery storage monitoring, and load management.

## 📱 Features

- **Live Smart House Hero**: 3D IoT house with real-time connector callouts for Solar (kW), Grid (kW), Battery SOC (%), and Household Load (kW).
- **Financial & Ecological Metrics**: Weekly export earnings in INR (₹) and CO₂ offset tracking.
- **System Overview Meters**: Battery State of Charge (SOC), Source Monitoring, and Load Consumption with colored status indicators (Optimal / Good / Moderate).
- **Floating Dark Pill Navigation**: High-contrast bottom tab bar for fast switching between Home, Wallet, Devices, and Profile.
- **Pull-to-Refresh IoT Simulation**: Interactive real-time telemetry updates.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- Expo Go app on your phone ([iOS App Store](https://apps.apple.com/app/expo-go/id982107779) / [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent))

### 2. Run the App

From the project directory:

```bash
# Start the Expo development server
npm start
```

### 3. Open on Device or Browser

- **iOS / Android**: Scan the QR code shown in the terminal using the Expo Go app or Camera app.
- **Web Browser**: Press `w` in the terminal to launch web preview.
- **Android Emulator**: Press `a` in the terminal.
- **iOS Simulator**: Press `i` in the terminal (macOS only).
